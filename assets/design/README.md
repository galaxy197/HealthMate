# Reference v2 illustrations

12 small PNGs (including the blue flame) exported from the user's editable HealthMate UI Kit v2, supplied for this project. These are decorative paths from `figma-plugin/design.json`, not full-screen screenshots or health data fixtures.

Re-export from the project root:

```text
node tool/import_reference_art.cjs <path-to-design.json> <path-to-sharp-module>
```

The original kit remains in the user's Downloads folder. No font files from the kit are imported; the app retains its existing BeVietnamPro font.
